My UI for KOReader

Started as a fork of [Simple UI](https://github.com/doctorhetfield-cmd/simpleui.koplugin) v1.5.0, but I added many of my own changes and removed some functional I don't use.

Require my [Book Statistic](https://github.com/anareaty/koreader-book-statistics) plugin to work properly.

Designed to use with list view of the library. 

Focused on Russian language (other language files will not be updated).
